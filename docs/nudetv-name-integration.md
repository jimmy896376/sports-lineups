# 누드TV 라인업 이름 매칭 수정 명세

대상: 운영자 PC의 `/nude/lineups/` 화면 코드. GitHub 저장소에는 이 화면 소스가 없으므로 화면 담당자가 적용해야 합니다.

## 확인된 문제

GitHub 이름 사전에는 `Joan Garcia → 조안 가르시아`와 `Victor Lindelof → 빅토르 린델뢰프`가 있었지만, 누드TV 화면은 공급자 표기가 바뀌면 사전 키를 놓쳤습니다. GitHub는 수집 중 관찰한 정확한 별칭을 추가하도록 수정했지만, 첫 관찰부터 다음 배포 전까지의 빈틈은 화면 조회에서 해결해야 합니다.

## 화면 조회 규칙

1. `name-catalog.json`의 `players`와 `teams`를 페이지 시작, 수동 새로고침, 주기 갱신 시 함께 갱신합니다. 응답의 `schemaVersion === 1`과 값 형식을 확인한 뒤 교체합니다. 요청 실패 시 마지막 정상 사전을 유지합니다.
2. 원문과 사전 키를 먼저 정확히 비교합니다. 없으면 `Ł/ł`을 `L/l`로 바꾸고, NFD 정규화 후 U+0300–U+036F 결합 부호만 제거합니다. 이어서 소문자화하고 유니코드 문자·숫자 외 문자를 제거한 키로 비교합니다. 일본어 탁음 부호 등 다른 문자권의 결합 부호는 제거하지 않습니다.
3. 정규화 키가 두 선수의 서로 다른 한국어 이름과 충돌하면 자동 선택하지 않습니다. 원문을 유지하고 검수 목록에 기록합니다.
4. 팀명과 선수명 양쪽에 같은 조회 규칙을 적용합니다. 부상자, 선발투수, 예상·확정 라인업, 검색 결과에도 같은 함수를 사용합니다. 화면 일부에 별도 변환 함수를 두지 않습니다.
5. 한국어 이름이 확인되지 않았으면 원문을 유지합니다. 검색 결과를 브라우저에서 즉석 음역해 확정 표기로 게시하지 않습니다.

## 필수 검증

- `Joan Garcia`, `Joán García`는 모두 `조안 가르시아`.
- `Victor Lindelof`, `Victor Lindelöf`는 모두 `빅토르 린델뢰프`.
- `Kim Min-Jae`와 `Kim Min-jae`는 동일한 검증 표기.
- `ベイスターズ`와 `ヘイスターズ`는 서로 다른 키.
- 사전에 없는 `Unknown Player`는 원문.
- 네트워크 실패 뒤에도 마지막 정상 사전이 화면에 유지됨.
- 영어 모드에서는 선수·팀 원문 또는 검증된 영문 풀네임이 표시됨.

## 배포 확인

수정 배포 뒤 누드TV 스테이징에서 위 사례가 선발 명단·부상 명단 양쪽에 반영되는지 확인합니다. GitHub Actions 성공만으로 완료 처리하지 않습니다.
